# BodyPath v0.11.62

This build replaces the old push-up icon asset pack with a lightweight minimalist SVG set.

## Changes
- New low-size white SVG variant icons
- Old variant asset files removed
- Journey stars styled in gold
- Variant icon circles removed from the artwork
- Existing logic and saved training data remain compatible

Deploy by replacing the full app folder or at least `app.js`, `style.css`, `index.html`, and the new `variant-*-min.svg` files.
